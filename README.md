# Customer Intelligence Platform

Enterprise Streamlit dashboard for customer segmentation, churn prediction, revenue forecasting, and retention action planning.

## Streamlit Cloud deployment

Use these settings in Streamlit Community Cloud:

- Repository: `MOHAMMED-GHANIM-SIDDIQUI/customer-intelligence-platform`
- Branch: `master`
- Main file path: `app.py`
- Python version: `3.12`

The app dependencies are declared in `requirements.txt`.

## Local run

```bash
pip install -r requirements.txt
streamlit run app.py
```
